# MR sculpted metal symbols

Current application assets are 27 independently authored SVGs, generated by
`python3 scripts/build_sculpted_icons.py`. They use multi-stop silver reflections,
indigo enamel, crimson accents, hardware seams and small fastener details.
No square backing plate or emoji is used. Green/amber/red retain status meanings.
The Government strip has 12 distinct symbols: Evidence Management uses a sealed
box and Training uses laboratory glassware. Navigation displays vectors at 44 px.

PROVENANCE.json records current output hashes and authorship. These SVGs replace
the flat Fluent color variants; no downloaded Microsoft geometry is used in the
current sculpted assets. Downloaded Fluent originals and their license remain
archived under assets/icon-sources/fluent. The earlier fetch_professional_icons.py
reconstructs the historical flat variant; rerun build_sculpted_icons.py afterwards
to restore the current application set.
