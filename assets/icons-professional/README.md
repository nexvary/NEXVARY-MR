# Professional unframed MR symbols

Source: https://github.com/microsoft/fluentui-system-icons
Pinned revision and per-file URLs/SHA-256 receipts: PROVENANCE.json.
License: MIT; original license in assets/icon-sources/fluent/LICENSE.

24 official colored vectors were freshly downloaded and verified against the
existing pinned-source hashes. The independent MR checkbox glyph is retained as
the 25th asset. No boxed background, chrome plate or enclosing frame is added.
Original symbol geometry is preserved. Selected warm decorative accents use a
restrained crimson palette; Home uses silver body and indigo roof. Semantic
success/error/warning colors remain explicit.

Rebuild: python scripts/fetch_professional_icons.py
Navigation renders these vectors at 40 px with high-resolution SVG source sizing,
12 px captions, tooltips, keyboard focus and selection underline.
