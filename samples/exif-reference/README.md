# Synthetic Exif reference

`reference.jpg` is a 16×12 solid-color image created for this repository using
Pillow 12.3.0 with independently serialized Exif tags. It contains synthetic
camera names and dates, no real person, device, location or photograph.
`reference.json` records the exact source hash and expected allowlisted values.
The test reads this committed fixture without requiring Pillow at runtime.

This generated fixture is dedicated to the public domain under CC0-1.0.
No Pillow code or binary is included or bundled with NEXVARY-MR.
