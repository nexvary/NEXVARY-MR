# Experiment results

Keep signed/reviewed result records here. Never commit seized-device personal data, credentials, malware samples, or restricted investigative evidence. Record `experiment_id`, `device_id` (synthetic pseudonym), `started_at_utc`, `completed_at_utc`, `tool_versions`, `observations`, `evidence_sha256`, `reviewer`, `status`. Do not mark an experiment `verified` without an actual reproducible test and evidence.
