# Approved later phases

Complete and review the current Windows native interface first. Do not build a new Setup until the owner reviews actual screenshots. No paid live search is authorized by this document.

## Ubuntu
Reuse the existing Qt application and adapters. Windows DPAPI cannot be claimed on Ubuntu: select and validate appropriate Linux credential storage, packaging, device permissions and dependencies. This phase is not implemented or accepted yet.

## Nexvary server
Move provider credentials, supplier-cost accounting, pricing policy, organizational licensing and privileged request orchestration to a Nexvary-controlled service. Retain USB detection and device operations on the native client. Use authenticated encrypted requests, explicit paid-operation consent, idempotency and durable request IDs; never replay a billable request automatically. Agree institutional data routing, retention and deletion requirements before deployment. Do not provision a server or migrate customer credentials during Windows UI repair.

## Distribution
Distribute proprietary executable components without their source, while complying with Qt/LGPL and all third-party license duties. A client binary cannot prevent reverse engineering; server-side logic remains private. The existing public GitHub repository and its published history are not made private by adding license wording; repository visibility and distribution permissions require a separate deliberate change.
