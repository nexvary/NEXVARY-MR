`UPSTREAM_SNAPSHOT_2026-10-23.json` records repository metadata observed through GitHub. The Shizuku API's last push is older than the other sampled projects; this is a maintenance-review input, not a vulnerability finding. No complete CVE or source-code security audit was performed for these dependencies.

Architecture choice: retain one native operation/identity policy; use narrow external-process adapters only when justified; parse working copies and record version/hash/provenance. Do not link or bundle a component merely because an executable is detected. Existing adapters, candidates and blocked functions must remain distinguishable in UI and documentation.

Detailed historic forensic candidates and pinned license sources remain in `docs/forensics/UPSTREAM_REVIEW.json`; the TSK status has been corrected to reflect the implemented external mmls adapter.
