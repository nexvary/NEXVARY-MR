# NEXVARY MR — دليل الاستخدام / User guide

نسخة تطوير لمحطة صيانة Windows 10/11 x64. تتضمن الحزمة مكتبات Microsoft C++ الضرورية بجوار البرنامج؛ لا يحتاج التثبيت لكل مستخدم إلى تثبيت Runtime على مستوى النظام. شغّل `NEXVARY-MR.exe` من مجلد النسخة المحمولة بعد فك الضغط بالكامل، أو استخدم المثبت. لا تحتاج كتابة أوامر لإجراء الوظائف الأساسية. الملفات الناتجة غير موقعة رقميًا، ولا تُعد إصدارًا تجاريًا نهائيًا قبل اعتماد بوابات الاختبار.

## البداية والأجهزة

1. اختر العربية أو الإنجليزية من الواجهة؛ اتجاه العربية RTL.
2. تعرض لوحة الأدوات ما إذا كانت ADB وFastboot وscrcpy متاحة. ثبّتها من مصادرها الرسمية؛ لا يقوم البرنامج بتحميلها تلقائيًا.
3. وصّل هاتف Android بكابل بيانات، وفعّل USB debugging بموافقة مالكه، ثم وافق على رسالة تفويض الكمبيوتر على الهاتف.
4. حدّث كشف ADB أو Fastboot، ثم اختر الجهاز المطلوب من القائمة قبل قراءة خصائصه أو سجلاته.
5. عند ظهور `unauthorized` وافق على التفويض على الهاتف. عند `offline` افحص الكابل والمنفذ والتعريف؛ لا تتكرر محاولات تغيير النظام تلقائيًا.
6. عرض الشاشة يشغّل scrcpy كبرنامج مستقل عند ضغطك عليه. يتطلب أداة مثبّتة وجهازًا مصرحًا به.

تعمل عمليات الفحص في الخلفية مع مهلة وإمكانية الإلغاء. لا تُعد المعلومات الناقصة دليلًا قطعيًا على عطل. فحص التعريفات يعطي جردًا تشخيصيًا ولا يثبت تعريفات Windows تلقائيًا. دعم iPhone/Apple المباشر غير منفذ في هذه النسخة؛ لا تُستنتج دعمه من الصورة المرجعية للتصميم.

## التشخيص والبرامج الثابتة

استخدم التشخيص كقائمة فحص إرشادية. السجل ومعلومات الإقلاع المتاحة تساعد الفني، لكنها لا تثبت سبب Bootloop بمفردها. لا توجد عملية تفليش أو مسح أو فك قفل أو تجاوز FRP/iCloud أو تعديل IMEI. تحقق التوافق لا يغني عن مطابقة الشركة والموديل والمنطقة وإصدار المحمل وتوقيع ملف الشركة عند تنفيذ استعادة رسمية خارج البرنامج.

## المخططات والقياسات

العارض المدمج يستخدم صيغة NEXVARY JSON الموثقة وملف تدريب اصطناعي. أسماء المكونات والقيم في التدريب ليست مخططًا حقيقيًا لهاتف ولا مرجعًا لإصلاح لوحة فعلية. لا يدعم حاليًا كل صيغ `.brd` أو `.pcb` التجارية.

استورد فقط ملفات تملك حق استخدامها، وابحث عن اسم المكون أو الشبكة ثم استخدم التكبير والتحريك. سجّل القياس والملاحظة واحفظ جلسة المخطط من الواجهة. المقارنة بالقيمة المرجعية متاحة فقط عندما يحتوي ملفك على مرجع؛ الوحدات وشروط القياس يحددها مصدر المخطط. لا تتصل النسخة الحالية بملتيميتر أو أوسيلوسكوب، ولا تستقبل قياسات حية تلقائيًا.

## الورشة والنسخ الاحتياطي

أنشئ أمر صيانة ببيانات العميل والجهاز والعطل والفني. حدّث الحالة وأجرة العمل وأضف قطع الغيار؛ ترتبط حركة القطع بالأمر. احتفظ بأرقام الاتصال والملاحظات الضرورية فقط، ولا تسجل كلمات مرور أو رموز قفل الأجهزة.

يمكن تصدير قائمة الأوامر وفاتورة الأمر، مع حفظ الفاتورة بصيغة PDF وطباعتها من عارض PDF. هذه فاتورة تشغيلية بسيطة؛ لا تفترض توافقًا ضريبيًا أو دعم منظومة الفاتورة الإلكترونية.

استخدم النسخ الاحتياطي قبل الاستعادة. الاستعادة تستبدل قاعدة بيانات الورشة بعد تأكيد صريح وفحص الملف، وتحتفظ بنسخة قبل الاستعادة عند الإمكان. افحص سلامة قاعدة البيانات من الواجهة واحفظ نسخة ثانية على وسيط آمن منفصل. قواعد SQLite والنسخ ليست مشفرة تلقائيًا؛ احمِ حساب Windows والقرص وقيّد الوصول إلى الملفات. لا ترفع بيانات العملاء عند الإبلاغ عن خطأ.

## الإغلاق وحدود التحقق

زر إغلاق النافذة يغلق التطبيق؛ العمليات الخارجية المستقلة مثل scrcpy قد تستمر وتُغلق من نافذتها. احفظ جلسة المخطط قبل الخروج؛ لا تعتبر الملاحظات غير المحفوظة محفوظة تلقائيًا. أعمال الورشة تُحفظ عند نجاح العملية وتظهر أخطاء الحفظ للمستخدم.

نجاح اختبارات المحاكاة أو فحص بدء التشغيل لا يثبت عمل كل هاتف أو تعريف USB أو مخطط. قبل الاعتماد الإنتاجي يلزم اختبار جهاز Android فعلي، واجهة Windows العربية والإنجليزية على أحجام شاشات مختلفة، استعادة نسخة على حاسوب مستقل، تشغيل portable على Windows نظيف، والتحقق من حقوق ملفات المخططات المستخدمة.

## English quick start

Extract the entire portable ZIP and double-click `NEXVARY-MR.exe`, or use the per-user installer. Install optional ADB/Fastboot/scrcpy from their official sources. Authorize USB debugging on your own or an explicitly authorized Android device, select the intended serial, and start read-only diagnostics. No firmware flashing or security bypass is implemented.

Use the workshop for local repair records, stock and operational invoices. Export invoices as PDF and print them from your PDF viewer. Back up the SQLite database before a confirmed restore; files are not encrypted automatically. The embedded boardview uses documented NEXVARY JSON with synthetic training data, not proprietary production board formats. Save board sessions before closing. Consult `THIRD_PARTY.md` and `INTEGRATIONS.md` for licensing and integration boundaries.


### اختيار أدوات Android دون تعديل PATH

من «جاهزية وإعدادات» اضغط «اختيار الأداة» بجوار ADB أو Fastboot أو scrcpy، ثم اختر الملف التنفيذي الرسمي بعد فك ضغطه. الاختيار يحفظ المسار ولا يشغّل الملف. زر «تلقائي» يلغي المسار المحفوظ ويعود للاكتشاف التلقائي. لا تختَر أدوات من مصدر غير موثوق.

The readiness page provides executable file pickers for ADB, Fastboot and scrcpy. Selecting a file validates and saves its path without executing it. **Auto** clears the saved override and restores PATH discovery.

### مؤشرات السجلات

بعد قراءة Logcat من جهاز مصرح به، يمكن عرض أنماط التعطل والذاكرة والاتصال ورفض الصلاحيات مع عدد مرات ظهورها وأسطر الدليل. هذه مؤشرات نصية محدودة؛ عدم ظهورها لا يثبت سلامة الجهاز. لا يُحفظ محتوى السجل الخام تلقائيًا في سجل الورشة.
