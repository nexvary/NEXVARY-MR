# بدء العمل المباشر

يفتح التطبيق مساحة العمل مباشرة دون إنشاء حساب أو كلمة مرور داخل البرنامج. يحمي مستخدم Windows الحالي البيانات والمفتاح بواسطة DPAPI. لا تنتهي مساحة العمل تلقائيًا بعد 15 دقيقة.

1. افتح الاستخبارات ← إعداد الاستخبارات، وأدخل مفتاح API ثم احفظه. لا يلزم حساب آخر أو تفعيل إذن مستقل.
2. وافق على اختبار الاتصال وجلب الأدوات. الاختبار لا يستدعي أدوات البحث تلقائيًا.
3. اختر الأداة وأدخل البيانات. الرصيد والتكلفة غير متحقق منهما؛ أكّد كل إرسال قد يخصم رصيدًا. لا إعادة إرسال تلقائية.
4. البحث المباشر لا يتطلب فتح قضية أو تسجيل جهاز. افتح قضية عند الحاجة لحفظ التقرير وربطه بالأدلة. النتائج غير متحققة حتى مراجعتها.

تُحفظ الحسابات والقضايا القديمة دون حذف. تتاح القضايا المحمية ضمن ملف مستخدم Windows نفسه. يُنقل مفتاح API السابق تلقائيًا إذا وُجد مفتاح محفوظ واحد فقط؛ عند تعدد المفاتيح أدخل المفتاح الذي تريد استخدامه.

تحليل الهاتف المحلي عبر المحرك الخارجي يحتاج محركًا مراجعًا ومساره وبصمة بنائه. لا يعني عرض هذه الواجهة توافر خدمة بحث حية أو رصيد مدفوع.
