# NEXVARY MR — بدء العمل

## الحساب والقضية

1. من «الدخول / الحسابات»، أنشئ المسؤول الأول. يدخل البرنامج بهذا الحساب بعد نجاح الإنشاء.
2. حساب المدير لإدارة المستخدمين والمنح، ولا يقرأ القضايا تلقائيًا. لإنشاء القضايا، املأ بيانات مستخدم جديد واختر «إنشاء حساب المحقق والدخول إليه».
3. افتح «قضية جديدة». أكمل بيانات القضية، السند والنطاق، والضبط والملاحظات، ثم «المراجعة والحفظ».
4. الحقول المطلوبة مميزة بنجمة. تظهر أسماء الحقول الناقصة عند الحفظ، ولا تُحذف بيانات النموذج عند رفضها.
5. بعد الحفظ يظهر تأكيد. لتعديل القضية المفتوحة اختر «تحرير البيانات». القضايا التي يملكها مستخدم آخر تحتاج منحة وصول.
6. تسجيل الخروج أو تغيير الحساب يمسح مسودة النموذج وعرض القضية لحماية بيانات الحساب السابق. لا يحذف سجلات القضية المحفوظة.

## الاستخبارات وLampyre MCP

افتح «الاستخبارات» بجانب «لوحة التحكم الأمنية». يمكن فتح الصفحة قبل تسجيل الدخول أو اختيار قضية. تطبّق صلاحيات الحساب والقضية على تنفيذ الطلبات الحالية.

- الوضع العادي يبدأ بإعدادات حقيقية فارغة، وليس ببيانات اصطناعية.
- سجّل الدخول بحساب العمل المحلي. أدخل رابط MCP النهائي ومفتاح API المناسب من حساب Lampyre. لا تضع كلمة مرور الموقع أو مفتاح ترخيص برنامج Windows في حقل API.
- يدعم هذا الموصل Streamable HTTP، ومفتاح Bearer، واستجابات JSON وSSE. لا يخمّن عناوين REST الخاصة بالمزود ولا ينفذ OAuth تلقائيًا.
- «حفظ الإعدادات» لا يجري اتصالًا. على Windows يمكن حفظ المفتاح محميًا بـDPAPI للحساب المحلي المحدد. لا يوجد تخزين دائم غير مشفر بديل في الإنتاج.
- فعّل صلاحية «التحليل الخارجي» من الإدارة وفق مراجعة حساب آخر مخوّل. يشمل هذا اختبار الاتصال نفسه. ثم وافق على اختبار الاتصال واختر «اختبار الاتصال وجلب الأدوات». ينفذ التهيئة واكتشاف الأدوات فقط، ولا يستدعي أداة بحث تلقائيًا.
- الأدوات والمعاملات تأتي من كتالوج الخادم. اختر الأداة وأكمل الحقول المطلوبة. الطلب الحقيقي يحتاج حسابًا مخوّلًا، وتفعيل «التحليل الخارجي» من الإدارة، وموافقة خاصة بالطلب.
- الرصيد وتكلفة الفوتونات لا يقرآن تلقائيًا في هذا الإصدار. راجعهما في حساب المزود قبل التنفيذ. لا يعرض البرنامج رصيدًا مفترضًا أو تقدير تكلفة غير موثق.
- تظهر النتيجة المرسلة من الخادم. يمكن حفظ نسخة JSON جديدة تتضمن وقت الاستلام والأداة وحالة عدم التحقق. النسخة المصدرة غير مشفرة، ولا تُرفق تلقائيًا كدليل بقضية.
- «إيقاف الانتظار» يوقف انتظار العميل؛ ليس إثباتًا أن المزود أوقف التنفيذ أو أعاد الرصيد. لا يعاد إرسال طلب بحث تلقائيًا بعد انقطاع الاتصال.
- الاتصال الفعلي وبيانات الحساب والصلاحيات والتكلفة تبقى بحاجة إلى تحقق بحساب Lampyre صالح. اختبار الخادم المحلي لا يثبت نجاح الاتصال بالمزود الحقيقي.

## العرض التجريبي والمساعدة

- «وضع عرض تجريبي منفصل» اختياري ومغلق افتراضيًا؛ لا يتصل بالمزود ولا يستهلك رصيدًا. تُمسح بياناته عند إغلاقه أو مغادرة صفحة الاستخبارات.
- روابط الحساب والمساعدة الرسمية المحددة تُفتح بعد تأكيد منفصل دون إرسال بيانات القضية. لا يمنح ذلك صلاحية بحث أو تشغيل أدوات.
- الرسائل الأساسية عربية، وJSON والتفاصيل التقنية اختيارية. أعداد الأطلس والأدوات وخطط التجارب هي سجلات معرفية، وليست نتائج اختبار هواتف.
